# 🐭 小鼠测毒计算器 (Mouse Toxic Test Calculator)

这是一个基于 Python 和 CustomTkinter 开发的图形化工具，用于解决经典的“老鼠测毒”信息论算法问题。

## 📖 项目背景
**经典问题**：有 `N` 瓶水，其中 **1 瓶有毒**。用老鼠做实验，老鼠喝到毒水后一段时间会死亡。最少需要几只老鼠，能在一次实验后找出有毒的那瓶水？

本项目通过图形化界面输入总瓶数，自动计算最少需要的老鼠数量，并生成每瓶水的**“二进制编码喂水方案”**。

## ✨ 功能特性
- **现代化 GUI**：基于 CustomTkinter 构建，支持暗黑/亮色模式，界面美观。
- **智能计算**：自动利用公式 $k = \lceil \log_2(N) \rceil$ 计算最少所需老鼠数。
- **直观展示**：通过二进制编码直观展示每瓶水的喂食方案（`1` 代表喂，`0` 代表不喂）。
- **延迟动画**：计算结果前增加 1 秒延迟，营造沉浸式的计算体验（使用 GUI 定时器实现，不卡顿界面）。

## 🧠 算法原理解析
本工具的核心思想是 **二进制编码** 与 **信息论**：

1. 每只老鼠有 **生/死** 两种状态，对应二进制的 `0` 和 `1`。
2. 如果有 $k$ 只老鼠，实验结束后会产生 $2^k$ 种不同的死亡组合。
3. 要想覆盖 $N$ 瓶水，必须满足 $2^k \ge N$，即最少老鼠数：

$$
k = \lceil \log_2(N) \rceil
$$

**举个例子**：8 瓶水，只需 3 只老鼠（因为 \(2^3 = 8\)）。

- 第 0 瓶（`000`）：三只老鼠都不喝。
- 第 1 瓶（`001`）：鼠 3 喝。
- 第 5 瓶（`101`）：鼠 1 和 鼠 3 喝。

实验后，若鼠 1 和 鼠 3 死亡，对照编码 `101`，即可锁定第 5 瓶有毒。
